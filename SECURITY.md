# Security

Please report security problems to support@facilo.es, and we will reply by email.

Support period: each Facilo Botón de Arrepentimiento release gets security fixes for 5 years from its release date. The Pro version gets security fixes for 5 years from purchase, and they reach lapsed Pro licences on request.

The software bill of materials is in `sbom.cdx.json` (CycloneDX 1.5).
